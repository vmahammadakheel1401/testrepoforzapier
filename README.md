# Calculator App

A simple browser-based calculator built with HTML, CSS, and JavaScript. It supports standard arithmetic operations and includes a clean, responsive interface for desktop and mobile use.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Decimal support
- Percentage calculation
- Delete and clear actions
- Keyboard support for quick input
- Responsive layout with a modern calculator-style design

## Project Structure

- `index.html` — calculator layout and UI structure
- `styles.css` — styling and responsive design
- `script.js` — calculator logic and event handling

## How to Run

1. Open the project folder in your terminal.
2. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

3. Open the app in your browser:

   ```text
   http://localhost:8000
   ```

## Usage

- Click the calculator buttons to perform operations.
- Use the keyboard for quick calculations:
  - Numbers: `0-9`
  - Decimal: `.`
  - Operators: `+`, `-`, `*`, `/`
  - Equals: `Enter` or `=`
  - Clear: `Escape` or `C`
  - Delete: `Backspace`

## Notes

This project is intentionally lightweight and easy to extend if you want to add features such as scientific functions, history, or a dark/light theme.
